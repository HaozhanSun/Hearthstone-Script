# MCTS lethal telemetry checkpoint — 2026-09-10

## Scope

This checkpoint adds read-only, shared telemetry at the common MCTS dispatch
boundary. It applies to every strategy that extends `MCTSDeckStrategy`,
including Pirate Warrior and Pirate Demon Hunter. The telemetry does not alter
MCTS scoring, filtering, phase fences, taunt handling, hero-power ordering, or
the selected action.

## What is recorded

Before a non-EndTurn action is dispatched, the controller evaluates the live
attack actions currently generated by the card parser. The JSONL event is
`mcts_lethal_telemetry` and contains:

- `totalAttack`: sum of currently legal face attacks from ready minions plus a
  currently legal hero/weapon attack;
- `enemyHeroHealth`: opposing hero blood remaining at the pre-action snapshot;
- `canLethal`: `totalAttack >= enemyHeroHealth` when at least one legal face
  action exists;
- `decision`: `HERO`, `TRADE`, `OTHER`, or `NONE` for the selected action;
- `reason`, `attackableAttackers`, `faceAttackers`, `tauntCount`, selected
  target, and a state fingerprint.

When the same strategy sees the same game/state/decision again during a live
rescan, the short `MCTS_LETHAL_TELEMETRY ...` line and JSONL event are emitted
once. A changed state or selected decision receives a new replay sequence.
